Three Layers

🧠

Layer A — Strategy Engine

Deterministic rebalance loop: read balances + ETH price, decide via drift bands, execute through KeeperHub. Reproducible demo. LLM layer for natural-language strategies via MCP.

💳

Layer B — x402 Gateway

Pay-per-execution service. Clients pay USDC per call → agent fulfills via KeeperHub → returns tx link. Settles on Base USDC (x402) or Tempo USDC.e (MPP).

📊

Layer C — Audit Dashboard

Live web UI streaming every read, decision, execution (with real tx link), retry, and x402 payment over SSE. Clickable links to Etherscan.
