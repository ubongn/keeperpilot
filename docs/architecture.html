🧠 Layer A

Strategy Engine

Deterministic rebalancing loop — reads portfolio state, calculates drift from target allocation, executes corrective transactions. Rule-based so the demo never depends on an LLM not hallucinating.

💰 Layer B

x402 Pay-Per-Execution Gateway

HTTP service where external clients request an onchain execution ("swap 0.01 ETH→USDC") and pay per-call via the x402 protocol. Unpaid requests receive a standard HTTP 402 payment challenge.
